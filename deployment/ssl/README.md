# deployment/ssl/

Placeholder. Phoenix's recommended hosting providers (Vercel, Railway) both issue and auto-renew TLS certificates for custom domains automatically once DNS is correctly pointed — no manual certificate management is expected. This folder exists to document that expectation and record confirmation (once live) that HTTPS is enforced and certificates are auto-renewing, not to store certificate files or private keys.

If a future hosting choice requires manual certificate handling, document the process here — but do not store the certificate's private key in this repository under any circumstance.
